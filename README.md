# Laravel + Vue.js Test Project

### To quick start run:
```
make start
```

### Instruction

1. To prepare project for building:
```
make build
```
After this edit your .env file as you need

2. To build project:
```
make build
```

3. To run project:
```
make up
```

4. To prepare project for use:
```
make prepare
```

5. To stop services:
```
make down
```

6. To get logs:
```
make logs [service]
```

7. To restart services:
```
make restart [service]
```

8. To execute commands in services:
```
make exec [service] [command]
```
